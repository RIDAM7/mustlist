# Reviewers

Reviewers approve proposals for their topics; their approvals count toward a card becoming verified. GitHub requests their review automatically through [`.github/CODEOWNERS`](.github/CODEOWNERS), which must list the same people.

| Topic      | Reviewers            | Since      |
| ---------- | -------------------- | ---------- |
| All topics | @RIDAM7 (maintainer) | 2026-11-14 |

## Becoming a reviewer

Three merged cards **or** three substantive reviews in a topic, then a maintainer nominates you in a pull request that adds you here and to `CODEOWNERS` (for example `cards/auth/** @RIDAM7 @you`).

## What reviewers do

- Use the reviewer checklist in [CONTRIBUTING.md](CONTRIBUTING.md#reviewer-checklist).
- Approve on the proposal page or on GitHub. Request changes with a reason, and comment on single fields from the **Changes** tab.
- Never approve your own proposal; GitHub and the card guard ignore it anyway.
